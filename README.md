## 为什么有这个版本

我看到原作者有一段时间没有更新和修复，而自己最近需要在电脑上使用这个工具，因此使用 Codex 对本地便携版进行了修复。

如果你的电脑无法运行或遇到其他兼容问题，可能需要自行使用 AI Agent 工具排查和修复，例如 Codex、WorkBuddy 等。下载和使用前请先阅读下面的适用电脑与注意事项。

## 适用电脑

推荐环境：

- Windows 11 64 位。
- NVIDIA RTX 20、30、40 或 50 系列显卡。
- NVIDIA 驱动支持 CUDA 12.8。
- 建议至少 4 GB 可用显存。
- 有足够磁盘空间存放源视频、临时文件和输出视频。

已在以下环境完成测试：

- Windows 64 位。
- NVIDIA GeForce RTX 3060 Laptop GPU。
- PyTorch 2.11.0，CUDA 12.8。
- 362 帧、832 x 1440 测试视频。
- 完整处理至 100%，输出视频带 AAC 双声道音频。

不支持或不能保证可用：

- macOS、Linux、Windows ARM 和 32 位 Windows。
- 将 AMD 或 Intel 显卡作为 CUDA 推理设备。
- 没有兼容 NVIDIA 显卡的电脑。
- 与测试环境差异较大的系统、驱动或显卡组合。

## 本版包含的修复

- 使用 CUDA 版 PyTorch 和适用于 NVIDIA GPU 的推理路径。
- 处理视频时不再弹出 FFmpeg 黑色控制台窗口。
- 修复无控制台启动时进度条导致任务停在 1% 的问题。
- 修复音频合并失败后仍误报成功的问题。
- 输出 AAC 192 kbps 双声道音频。
- 支持将视频拖入窗口，空预览区域会显示拖放提示。
- 输出文件保存到源视频所在文件夹。
- 默认文件名使用 `_no_sub`；已有同名文件时自动追加序号，不覆盖原视频或旧结果。

## 下载与使用

> **重要：下方三个 `part*.rar` 文件必须全部下载，它们共同组成一个 WinRAR 多卷压缩包。**

### 为什么需要分卷

这里不是三个不同版本，也不是任选一个下载。

完整便携版压缩包约 4.94 GB，超过 GitHub 单个 Release 文件的 2 GB 限制，因此将它制作成了 WinRAR 多卷压缩包：

- `...part1.rar`
- `...part2.rar`
- `...part3.rar`

**必须把三个 `part*.rar` 文件全部下载。**少一个都无法解压。下载后请将三个文件放在同一个文件夹中，不要修改或重命名。

Release 页面还会显示 `Source code (zip)` 和 `Source code (tar.gz)`。它们是 GitHub 自动生成的源码归档，**不是**这个 Windows GPU 便携软件，不需要下载。

### 需要下载的文件

- 三个 `part*.rar` 分卷。
- `VSR...zip.sha256.txt`：完整压缩包的校验值。

### 操作步骤

1. 将三个 `part*.rar` 文件放在同一个文件夹，文件名不要修改。
2. 用 WinRAR 解压 `...part1.rar`。WinRAR 会自动读取 `part2.rar` 和 `part3.rar`。
3. 解压后会得到一个完整的 `VSR...zip`，再用 WinRAR 解压这个 ZIP。
4. 进入最终解压目录，双击 `启动 GPU 版.exe`。

不要只解压 `part2.rar` 或 `part3.rar`，也不要只从 ZIP 中运行启动器。必须使用最终完整解压后的文件夹。

输出默认保存在源视频所在文件夹，文件名为：

```text
原文件名_no_sub.mp4
```

## 文件校验

合并后完整 ZIP 的 SHA-256：

```text

```
